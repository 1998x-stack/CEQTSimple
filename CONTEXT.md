# CONTEXT.md — CEQTSimple

## Domain Glossary

### User Account (用户账户)
An authenticated identity identified by email + password. Each account has its own tasks, scoped via `user_id` foreign key in the database. Registration requires email and password (≥6 chars), no email verification. Login returns a JWT token (7-day expiry). Replaces the previous "Workspace" concept.

### Eisenhower Matrix (四象限矩阵)
A 2D grid mapping tasks by Importance (vertical axis, 1–7) and Urgency (horizontal axis, 0–12). The center is at importance=4, urgency=6. Tasks positioned top-left are "not urgent, not important" (Q3); top-right are "urgent, not important" (Q4); bottom-left are "not urgent, important" (Q1); bottom-right are "urgent, important" (Q2).

### Task (任务)
A unit of work with a position on the matrix, a category, optional subtasks, notes, an optional deadline, and an optional reminder time. Tasks can be completed (moves off the matrix), edited, or deleted.

### Deadline (截止时间)
A target completion datetime for a task. Drives the time-decay urgency calculation: as the deadline approaches, urgency automatically increases. Tasks without a deadline keep their manually-set urgency.

### Time-Decay Urgency (时间衰减紧急度)
A formula that recalculates a task's urgency based on how much time remains until its deadline. Triggered by the refresh button (🔄). The mapping is:

| Remaining Time | Urgency | Label |
|---|---|---|
| > 1 year | 0 | 1年 |
| 6–12 months | 1 | 半年 |
| 3–6 months | 2 | 3个月 |
| 1–3 months | 3 | 1个月 |
| 1–4 weeks | 4 | 1周 |
| 3–7 days | 5 | 3天 |
| 1–3 days | 6 | 1天 |
| 10–24 hours | 7 | 10小时 |
| 4–10 hours | 8 | 4小时 |
| 2–4 hours | 9 | 2小时 |
| 1–2 hours | 10 | 1小时 |
| 30min–1h | 11 | 30分钟 |
| < 30 minutes | 12 | 15分钟 |

### Subtask (子任务)
A checklist item within a task. Has text, done status, and a sort order for display sequence. The parent task's progress is shown as a ring around its dot on the matrix. Can be generated by the LLM polish system.

### Polish (润色)
LLM-powered task decomposition via DeepSeek API. Takes a task title + description, returns atomic subtasks with estimated importance, urgency, and duration. The user can accept, modify, or reject the suggestions before saving.

### Category (分类)
Predefined buckets for organizing tasks: work (工作), personal (个人), study (学习), health (健康), family (家庭), other (其他).

### Importance (重要程度)
How critical a task is, rated 1–7. 7 is highest importance. Default: 5. Determines vertical position on the matrix and dot color (cool blue → warm red).

### Urgency (紧急程度)
How soon a task needs attention, rated 0–12. Default: 8 (4 hours). Can be manually set or auto-calculated from deadline via time-decay. Determines horizontal position and dot opacity.

### Reminder (提醒)
An optional timestamp on a task, auto-computed as `deadline - 30 minutes` (user-adjustable). When the current time passes the reminder time, a browser notification fires. Best-effort in background tabs due to browser throttling.

### API Key (API密钥)
A DeepSeek API key required for the polish feature. Auto-detected from `DEEPSEEK_API_KEY` environment variable on backend startup. If missing, can be entered via the frontend header and is stored in server memory only (not persisted to disk).
