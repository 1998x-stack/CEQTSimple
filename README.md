# CEQTSimple

> 艾森豪威尔矩阵（重要性 × 紧迫性）任务管理——**单文件轻量版**。

## 📌 项目概述

`CEQTSimple` 是完整版 CEQT（Eisenhower Matrix 数字任务管理）的**简化单页实现**，将四象限任务管理浓缩进单个 `index.html`，无需后端即可直接打开使用，适合快速记录与演示。

## 📦 内容

- `index.html` — 单文件应用（四象限视图、任务增删改、优先级管理）
- `favicon.ico` — 站点图标

## 🚀 使用

直接用浏览器打开 `index.html` 即可开始管理任务。

> 完整版（FastAPI + Next.js + AI 决策教练）见同级仓库 [`CEQT`](../../web-apps/CEQT)。
